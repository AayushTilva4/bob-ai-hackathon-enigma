# Project Documentation Rules (Non-Obvious Only)

- **Single source of truth is `docs/HARBORAI_SPEC.md`.** It contains the complete product requirements, architecture, API design, domain model, and phase acceptance criteria. Any question about "what should this do?" is answered there.
- **`docs/implementation-status.md` tracks what is actually built.** Do not rely on the spec alone to determine what exists — always cross-reference with the status file and actual source files.
- **The port is fully simulated/synthetic.** There is no live AIS feed, no real vessel data, no real-time streaming. All data is generated by the synthetic data generator and simulation engine.
- **IBM BoB is used as the development assistant**, not as the runtime AI (unless explicitly configured). The runtime AI copilot target is watsonx, but only if actually configured and working.
- **"Phase acceptance criteria"** are defined precisely in spec section 31. Use these — not your own judgment — to decide if a phase is complete.
