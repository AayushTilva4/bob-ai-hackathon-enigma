## 1. Overview

HarborAI is a modular, backend-driven port operations optimization platform:

| Layer | Technology | Question Answered |
|---|---|---|
| **Simulation** | Python deterministic engine | What is happening in the port? |
| **ML Prediction** | XGBoost | What congestion will happen in 6 hours? |
| **Optimization** | Google OR-Tools *(Phase 5)* | What is the optimal berth/crane allocation? |
| **AI Copilot** | IBM watsonx *(Phase 9)* | How do we explain decisions to operators? |

## 5. Environment Configuration

Copy the example environment file:

```bash
# Linux / macOS
cp .env.example .env

# Windows (PowerShell)
Copy-Item .env.example .env
```

Open `.env` and set your values (defaults work out of the box with Docker):

```env
# Database — PostgreSQL connection strings
DATABASE_URL=postgresql+asyncpg://harborai:harborai@localhost:5432/harborai
DATABASE_URL_SYNC=postgresql+psycopg2://harborai:harborai@localhost:5432/harborai
TEST_DATABASE_URL=postgresql+asyncpg://harborai:harborai@localhost:5432/harborai_test

# App
ENVIRONMENT=development
LOG_LEVEL=INFO
SEED_DB=true
RANDOM_SEED=42

# Frontend
NEXT_PUBLIC_API_URL=http://localhost:8000
```

> [!NOTE]
> The default credentials (`harborai`/`harborai`) match the Docker Compose PostgreSQL container.
> If using your own PostgreSQL, create the user and databases first (see Step 7B).

## 6. Option A — Full Docker Setup (Recommended)

Starts **PostgreSQL + Alembic migrations + FastAPI backend + Next.js frontend** in one command.


Services started:
| Service | Port | Description |
|---|---|---|

Verify:
```bash
curl http://localhost:8000/api/health
# {"status":"ok","db":"connected","version":"0.1.0"}
```

## 7. Option B — Manual Local Setup

### Step 1 — Start PostgreSQL

**With Docker (just the database):**
```bash
docker compose up -d db
```

**Without Docker — create the database manually:**
```sql
-- Run in psql as superuser
CREATE USER harborai WITH PASSWORD 'harborai';
CREATE DATABASE harborai OWNER harborai;
CREATE DATABASE harborai_test OWNER harborai;
GRANT ALL PRIVILEGES ON DATABASE harborai TO harborai;
GRANT ALL PRIVILEGES ON DATABASE harborai_test TO harborai;
```

---

### Step 2 — Backend Setup

```bash
cd src/backend
```

**Create and activate virtual environment:**
```bash
# Windows (PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# Linux / macOS
python3 -m venv .venv
source .venv/bin/activate
```

**Install all dependencies:**
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

`requirements.txt` includes:
- `fastapi`, `uvicorn`, `pydantic`, `sqlalchemy`, `alembic`, `asyncpg`
- `xgboost`, `scikit-learn`, `joblib`, `pandas`, `numpy` *(Phase 4 ML)*
- `pytest`, `httpx` *(testing)*

---

### Step 3 — Run Database Migrations

```bash

```

Expected output:


### Step 4 — Start the Backend

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Verify:

```bash
curl http://localhost:8000/api/vessels

```

## 8. Generate Synthetic Datasets (Phase 3)

The ML model trains on synthetic datasets. Generate them before training.

```bash
cd src/backend

# Generate all 3 scenarios (normal, congestion_stress, demo)
python -m scripts.generate_dataset --scenario normal --seed 42
python -m scripts.generate_dataset --scenario congestion_stress --seed 42
python -m scripts.generate_dataset --scenario demo --seed 42

# Validate generated datasets
python -m scripts.validate_dataset

# (Optional) Import into PostgreSQL
python -m scripts.import_dataset
```

Datasets are saved to:
```
datasets/
└── synthetic/
    ├── normal/
    │   ├── operational_history.csv   ← ML features (2,160 rows)
    │   ├── congestion_history.csv    ← ML targets
    │   └── ...
    ├── congestion_stress/
    └── demo/
```

> [!NOTE]
> If `datasets/synthetic/` already exists in the repo, you can skip this step and go directly to training.

## 11. API Reference

Interactive docs available at: **http://localhost:8000/docs**

### Core Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health check + DB status |
| `GET` | `/api/vessels` | List all vessels |
| `GET` | `/api/berths` | List all berths |
| `GET` | `/api/cranes` | List all cranes |
| `GET` | `/api/yard` | List yard zones |
| `GET` | `/api/routes` | List routes |
| `GET` | `/api/port-status` | Latest port state snapshot |

### Simulation Endpoints

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/simulation/start` | Start simulation clock |
| `POST` | `/simulation/pause` | Pause simulation |
| `POST` | `/simulation/reset` | Reset all simulation state |
| `POST` | `/simulation/advance` | Advance by N hours |
| `GET` | `/simulation/state` | Full simulation state |
| `GET` | `/simulation/kpis` | Real-time KPIs |
| `GET` | `/simulation/events` | Event history |

### ML Prediction Endpoints (Phase 4)

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/api/prediction/congestion` | Predict congestion risk (next 6h) |
| `GET` | `/api/prediction/status` | Model load status + metrics |
| `POST` | `/api/prediction/train` | Trigger background model training |
